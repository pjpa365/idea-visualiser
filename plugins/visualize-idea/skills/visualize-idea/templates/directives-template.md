# Directives

Save as `<input-name>-directives.md` next to the input text (e.g. `door-controller-directives.md` for `door-controller.md`). Plain text: fill in what you need and delete the rest. A directive overrides the same item in the project file.

## Name for the diagrams
(e.g. door-controller)

## Diagram types
(e.g. state and sequence; when given, the skill does not ask)

## Scope
Which parts of the text to visualize, and what to leave out.

## Level of detail
(e.g. overview only; or every message with its fields)

## Colour roles
Roles to use or avoid; hard colours, if any (e.g. "the emergency stop in red #D00000").

## Domain
Only when it differs from the project (e.g. network protocols).

## Versioning
- Diagrams: on / off
- Text copies: on / off

## Show the plan
- yes / no

## Diagram changes
- local change / full redraw
